# BOM Notes

## Rotary encoder
I used an EN11-VSM-0AF20 with no detents, but an EN11-VSM1AF20 can be used which has detents. Note, the shaft will probably be too long and require trimming. I could not locate an EN11-VSM0AF15 (or EN11-VSM1AF15) which has a shorter shaft.

## Resistors
All SM resistors are 1% tolerance, 1206 thick film of at least 250mW except R14 which should be at least 2.4W.

## Capacitors
All SM capacitors are 1206 NP0 or C0G except for the 22uF (25V) capacitors

## Inductors
All SM inductors are 1206 (or 0805) for as high SRF as possible (ie, greater than 30MHz), except for L1 which has a specific part number (1206F-100K-01). An alternative is the MLZ2012M150WT000 (it should be fine, but I have not tried it).
